Performance cache plugin powered by MR Panel. Manage page cache, browser cache, PHP tuning, and more.

== Description ==

MR Panel Cache provides server-level caching and performance optimization for your WordPress site, powered by MR Panel.

**Features:**

* **Page Cache** - Cache entire pages for faster load times
* **Browser Cache** - Set expiration headers for static assets
* **PHP Tuning** - Optimize OPcache, memory limits, and PHP settings
* **Minify** - CSS and JavaScript minification
* **Purge Cache** - Clear all cache or purge by specific URL
* **Dashboard** - Monitor cache status and performance

**Requirements:**

* MR Panel server management (https://mrpanel.com)
* This plugin works best when installed automatically through MR Panel

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/mr-panel-cache/`
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Go to Settings > MR Panel Cache to configure your MR Panel connection
4. Enter your MR Panel URL and API Key
